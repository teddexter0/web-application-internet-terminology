Internet Term 3

Web Browser

This page explains the web browser using its definition, role, and analogy.

Definition

A web browser is a software application used to retrieve, interpret, and display web content such as HTML pages.

Role

It sends HTTP requests to servers and renders the returned data into visual web pages for users.

Analogy

Like a translator that converts web code into something you can see and understand.
