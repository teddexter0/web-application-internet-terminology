Internet Term 12

HTML

This page explains HTML using its definition, role, and analogy.

Definition

HTML (Hypertext Markup Language) is the standard language used to create web pages.

Role

It structures content such as text, images, and links on the web.

Analogy

Like the skeleton that gives structure to a body.
