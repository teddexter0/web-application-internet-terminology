Internet Term 6

DNS

This page explains DNS using its definition, role, and analogy.

Definition

The Domain Name System (DNS) translates human-readable domain names into machine-readable IP addresses.

Role

It allows users to access websites using names instead of numerical IP addresses.

Analogy

Like saving someone’s name in your phone instead of memorizing their number.
