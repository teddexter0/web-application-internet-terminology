Internet Term 13

Web 1.0

This page explains Web 1.0 using its definition, role, and analogy.

Definition

Web 1.0 refers to the early version of the web with static, read-only pages.

Role

Users could only view information without interaction.

Analogy

Like reading a newspaper.
