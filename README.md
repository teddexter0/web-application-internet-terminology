# Internet Terminology Website

A multi-page school project that explains key internet concepts using definitions, roles, analogies, and diagrams.

## Author
Sande Ted Dexter

## Features
- 19 original internet terminology pages kept in the project.
- Bootstrap 5 CDN is used for layout, forms, buttons, spacing, and responsive columns.
- External CSS is linked through `css/style.css` and shared across the pages.
- Responsive design is applied for mobile, tablet, and desktop screens.
- The main navigation is simplified so the important pages are easy to find.
- The forms are front-end coursework demos only; they do not use a backend, database, or authentication system.

## Pages Added or Refined
- `contact.html` - polished contact page with contact details and a Bootstrap form.
- `blog-form.html` - publishing/admin-style blog post form.
- `signin.html` - modern centered sign-in card.
- `signup.html` - modern centered sign-up card.
- Existing internet terminology pages in `pages/` remain available from the homepage main content grid.

## Tech Stack
- HTML
- CSS
- Bootstrap 5 CDN
- JavaScript for the menu and slideshow behavior

## How to Run
Open `index.html` in a browser, then use the hamburger menu or homepage cards to navigate.

No build step is required because this is a static HTML/CSS project.
